# Milestone 15 — Unified Single-View `Today` (with Past-Day Navigation & Embedded Data Views) & Pure Data-View `Plan & Review`

Parent: [`milestones.md`](../milestones.md)

## Objective

Eliminate the split views on `Today` and `Plan & Review` (`B-01`, `B-02`):
1. Make `Today` a single unified view with a top **Date Navigation Bar** (for viewing past days and returning to Today) over the template-generated `daily/YYYY-MM-DD.md` note containing embedded ```` ```citrine ```` source code blocks that render live interactive data views inline.
2. Make `Plan & Review` (`Horizons`) a single unified, pure database-driven data view with no backing `.md` files required.

## Exit criteria

1. `Today` has no top/bottom split divider: it displays a top Date Navigation Bar (`◀ Prev | Date Picker | Next ▶` + `Back to Today` when viewing a past/other date) directly above the full-page `daily/YYYY-MM-DD.md` Live Preview editor.
2. Daily notes are created from an editable template (`.citrine/templates/daily.md`) that includes ```` ```citrine ```` fenced code blocks (supporting preset views like `top-focus`, `due-today`, `created-today`, `due-this-week`, `habits`, `schedule` and custom YAML filters).
3. `LivePreviewEditor` renders ```` ```citrine ```` blocks as interactive inline task/data views when the cursor is outside the block, and includes an **Insert Data View** toolbar button.
4. `Plan & Review` renders Weekly, Monthly, Quarterly, Yearly, and Future planning/review surfaces as pure database-backed data views (no split view and no `.md` files created for those views).
5. `flutter analyze` and all unit/widget tests pass.

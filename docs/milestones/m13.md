# Milestone 13 — App Shell, Hamburger Menu, About Screen, 7-Tap Debug Mode + Date Override & App Icon

Parent: [`milestones.md`](../milestones.md)

## Objective

Establish the Hamburger Menu (`Drawer`), About Screen, 7-tap Debug Mode unlock with an injectable app-wide clock override (`Override Current Date`), and the Citrine Crystal + Fountain Pen application icon (`FR-14`, `FR-15`).

## Exit criteria

1. `AppShellScaffold` provides a Hamburger menu (`Drawer`) housing secondary utilities (Recent Views, Data Import/Export, Planning Process Setup, Field Guide & Help, Settings, and **About Citrine**).
2. Navigating to **About Citrine** displays the Citrine emblem, version string, and overview; tapping/clicking the version string **7 times** enables **Debug Mode**.
3. When **Debug Mode** is enabled, the Hamburger menu displays a **Debug** section containing **Override Current Date** (and **Disable Debug Mode**).
4. Overriding the current date updates `appClockProvider` app-wide (`Today`, `Plan & Review`, reminders, and rituals) and displays a compact top-bar indicator pill (`Debug Date: YYYY-MM-DD [-1d] [+1d] [Reset]`).
5. The Citrine app icon (a yellow-gold faceted citrine crystal with a stylized fountain pen in front of it) is generated and installed across target platform assets.
6. `flutter analyze` and all unit/widget tests pass.
